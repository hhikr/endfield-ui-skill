# 做与不做

这些规则来自真实项目里一轮轮原型的评审。"不做"里的每一条，都是真的做出来、看过、被否决的。对照效果见 `templates/antipatterns.html`（截图 `examples/web/antipatterns*.jpg`）。

## 做

- 先选页面类型：阅读（安静）/ 展示（大胆）/ 控制台（大胆但要好用）。
- 浅色为默认，深色是完整的第二套主题。
- 一种强调色（默认 `#FFFA00`，可以按产品换，见 `variation.md`），只有三种含义：当前位置、可点击内容、醒目提醒；只做填充，上面写墨字。
- "标出当前位置的线"用 `--ef-trace`：浅色时是墨，深色时是黄。
- 切掉一个角 = 可以点。文字和切角之间留出至少一个切角宽的空白，切角放大时留白跟着放大。
- 用细线分区；列表用整行的记录，每一列都是真实字段。
- 用真实的统计数字装饰界面：篇数、字数、天数、进度，比空白的装饰更有工业感。数字、日期、编号用宽体等宽数字；日期写成 `2026.10.12`；编号补零写成 `No.016`；`当前 / 总数`。
- 界面用宽体几何英文（如 Saira）配中文黑体，可以很粗；英文标签大写、拉宽，前缀 `//`，中英成对。正文用黑体常规字重。
- 展示页大胆：超大实心字标加空心字标、空心大编号、切角画框和斜线纹影子、墨色滚动条。
- 控制台：深色命令栏，中间圆盘（手机上是大数字看板），看板对称但不成方格。
- App：底部标签栏当前项整格黄；顶栏不填色、不居中；主要按钮在触屏上静止就是黄底。
- 质感只用一点：斜线纹、两小片极淡的等高线。
- 动效短、硬、机械，每个对应一次操作，减少动效时全部关掉。按下用擦入，不用涟漪。
- 空状态写成完整的一句话。

## 不做

| 不做 | 为什么 |
| --- | --- |
| 黑底配黄色大字（尤其在浅色主题里） | 太像警示牌，刺眼，和"克制的黄"相反 |
| 用红色表示告警、失败、待审 | 红色一出现就显得出事了。告警用黄块和墨线；红色只留给删除 |
| 图表用红绿 | 同上；而且红绿色盲看不出区别。用灰柱，悬停的那根变成 `--ef-trace` |
| 大面积铺黄、黄底横幅 | 黄色就不再表示当前位置了 |
| 浅色主题里用黄色画线或写字 | 白底上只有 1.1:1，看不见 |
| 柔和投影、发光、霓虹、扫描线滤镜、装饰性渐变 | 那是另一种科幻（HUD / 赛博朋克），不是这种干净的工业感 |
| 圆角、胶囊按钮、圆形浮动按钮（FAB） | 和切角语言冲突。浮动操作改成切角的方块按钮 |
| Material 涟漪、iOS 默认圆角分组列表 | 平台默认样式要换掉：涟漪换成擦入，分组列表换成细线分隔的直角行 |
| 卡片网格（阅读页的文章列表、控制台的方格仪表盘） | 像后台模板。阅读页用记录行；控制台用围着圆盘的不规则看板 |
| 点阵、方格纸背景、闭合的山丘等高线 | 太满、太"设计感"；等高线要不闭合、像水流、极淡、只在两角 |
| 假技术文字、二进制串、条形码、坐标、十字标记、装饰小方点 | 官网用它们做质感，但对读者没有任何信息 |
| 满屏全大写英文 | 只在展示页和控制台的小标签上用 |
| 楷体、宋体、手写体、圆体，或等宽字体当正文 | 终末地的界面和正文都是干净的黑体；书卷气、可爱、"程序员"风的字都会把气质带偏 |
| 英文用普通窄字（Arial、Roboto 默认宽度）当标签 | 宽、几何、大写的英文是辨识度最高的一点 |
| 不打包英文宽体，指望系统字体 | 系统里没有宽体几何字，标签会退回普通字体，味道全没了 |
| 持续循环的装饰动画、弹跳、文字逐个缩放弹出、滚动触发的逐段淡入 | 动效要对应操作；一直在动的东西让人分心 |
| 用中间点 `·` 串字段 | 用竖线或斜线 |
| 使用游戏的字体、标志、图标、立绘、截图、文案 | 版权；而且照抄出来的只是"同人页"，不是"有这种气质的网站" |

## 反例对照

`templates/antipatterns.html` 把最常见的八种错误和正确做法并排放在一起：黑底大黄字、红色告警、圆角卡片网格、胶囊渐变发光按钮、点阵背景、假技术文字、方格仪表盘、浅色里的黄线和衬线字。动手前看一眼。
