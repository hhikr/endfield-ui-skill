# 变量：颜色、字体、字号

平台无关的数值在 `assets/tokens.json`（逻辑像素）；网页版定义在 `assets/endfield.css` 开头（`--ef-*` 变量），Flutter 版在 `templates/flutter/lib/ef/tokens.dart`。下面是含义和理由。对比度按 WCAG 公式算出。

## 颜色

### 浅色（默认）

| 变量 | 色值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| `--ef-paper` | `#F4F4F2` | 页面底色。比纯白暖一点、暗一点，让白色的纸和板能浮出来 | — |
| `--ef-panel` | `#FFFFFF` | 阅读页的白纸、控制台看板、输入框 | — |
| `--ef-ink` | `#161616` | 正文、标题，以及一切"有意义"的线 | 纸上 16.4:1，板上 18.1:1 |
| `--ef-ink-2` | `#5C5C5C` | 次要文字、字段标签、日期 | 纸上 6.1:1，板上 6.7:1 |
| `--ef-rule` | `#D9D9D6` | 1px 分隔线 | 装饰 |
| `--ef-chip` | `#E4E4E0` | 安静的填充：待机按钮、标签块 | — |
| `--ef-signal` | `#FFFA00` | **唯一的强调色**：当前位置 / 可点击内容 / 醒目提醒。默认黄，每个产品可以换一种（`variation.md`） | 墨字压黄 16.3:1；黄在白上 **1.1:1，看不见** |
| `--ef-on-signal` | `#161616` | 黄色上的字，两套主题都一样 | — |
| `--ef-trace` | = `--ef-ink` | 标出当前位置的线：目录当前项、阅读进度、列表悬停色条、图表的线 | — |
| `--ef-tag-bg` / `--ef-tag-fg` | 墨 / 白 | 编号标签 | — |
| `--ef-danger` | `#B3261E` | **只用于删除** | 白上 6.5:1 |
| `--ef-tri-a/b/c` | `#FF00F0` 强调色 `#00FFA2` | 三色条，中间一格跟着强调色 | 薄荷绿在白上只有 1.3:1，只做色块，不做线 |
| `--ef-mark` | 黄 55% | 荧光笔：选中文字、搜索命中 | — |
| `--ef-contour` | 墨 9% | 背景等高线 | — |
| `--ef-hatch` | 墨 22% 的 45° 斜线（/ 方向），1.5px 线、5px 空，周期 6.5px（垂直于线测量） | 斜线纹。原生画法沿 x 步进 9.2（= 6.5 × √2），见 `tokens.json` 的 `size.hatch` | — |

### 深色

深色是另一套完整主题，不是把浅色反过来。

| 变量 | 色值 | 说明 |
| --- | --- | --- |
| `--ef-paper` | `#191919` | 和官网的近黑一致，不用纯黑 |
| `--ef-panel` | `#222222` | |
| `--ef-ink` | `#EDEDED` | 纸上 15.0:1 |
| `--ef-ink-2` | `#A3A3A3` | 纸上 7.0:1 |
| `--ef-rule` | `#353535` | |
| `--ef-chip` | `#2E2E2E` | |
| `--ef-trace` | = `--ef-signal` | **深色里当前位置的线是黄色**（黄在 `#191919` 上 15.9:1） |
| `--ef-tag-bg` / `--ef-tag-fg` | `#3A3A3A` / 墨 | 编号标签在深色里退成深灰，避免满屏白块 |
| `--ef-danger` | `#FF8A7A` | |
| `--ef-mark` | 黄 22% | 浅一些，免得吞掉浅色字 |

**两套主题最重要的差别**：黄色在浅色里只能做填充，在深色里既能做填充也能做线。所以凡是"标出当前位置的线"，一律写 `var(--ef-trace)`，不要自己判断主题。

**切换**：默认跟随系统，并给用户一个手动切换。网页：`<html data-theme="light|dark">`，`fx.js` 的 `wireTheme()` 负责按钮和记忆；为了不闪烁，在 `<head>` 里用一行小脚本先写好 `data-theme`。原生 App：跟随系统外观（iOS `colorScheme`、Android `isSystemInDarkTheme()`、Flutter `ThemeMode.system`），设置里可覆盖。

### 用色规则

- 一屏里黄色的面积要小。它出现在：当前导航项、选中的筛选、当前编号、马克笔一句、"注意"小旗、需要处理的数值、悬停时的擦入。
- 阅读区正文只用墨、次要墨和纸；黄色只在链接下划块和 `mark` 上。
- 三色条只出现两处：页顶全宽、文章标题下方。
- 不要黑底配黄色大字。控制台命令栏是深色的，但上面的黄只是"当前分区"那一小块。
- 告警、待审、失败、磁盘快满：黄块加墨字。**不用红**。图表不用红绿。

## 字体

### 三个角色

| 变量 | 字体 | 用在 |
| --- | --- | --- |
| `--ef-font-ui` | Saira（可变，宽度 50–125、字重 100–900）+ 思源黑体 Noto Sans SC | 一切界面文字：导航、按钮、标签、编号、数字、标题、字标 |
| `--ef-font-text` | 思源黑体 Noto Sans SC 常规字重 | 供人阅读的内容：正文、详情、列表里的标题、摘要 |
| `--ef-font-mono` | 系统等宽 | 只给代码 |

宽度靠 `font-stretch`（网页）或可变字体的 `wdth` 轴（原生）：

| 变量 | 值 | 用在 |
| --- | --- | --- |
| `--ef-wide` | 112% | 字段：编号、日期、计数 |
| `--ef-wider` | 125% | 大写英文小标签、眉标、字标 |

为什么是 Saira：官网的英文标签是宽体、几何、全大写（接近 Novecento Wide 一类）。Saira 是开源（SIL OFL 1.1）的同类字体，而且一个可变字体文件就包含从窄到超宽的全部宽度和字重，所有平台都能打包。也可以换成别的宽体几何字体；**不要用游戏官方字体**。

- 中文：网页自托管思源黑体；原生 App 可以直接用系统中文字体（苹方、Noto Sans CJK），把 Saira 放在字体链的第一位、中文落到系统字体上。想要各平台完全一致，就把 Noto Sans SC 打包进去（体积较大，可只打包常用字子集）。
- 字重：正文 400，标签 600，按钮和标题 700，字标和大数字 800。
- 数字用等宽数字（`font-variant-numeric: tabular-nums`；Flutter `FontFeature.tabularFigures()`）。
- 英文小标签全大写、字距 0.14em；中文不加字距，不全角加空格。

### 自托管（网页）

```
npm i @fontsource-variable/saira @fontsource-variable/noto-sans-sc
```

```css
@import '@fontsource-variable/saira/standard.css'; /* 含宽度轴 */
@import '@fontsource-variable/noto-sans-sc/wght.css';
```

都是 SIL OFL 1.1，可以商用和自托管；把许可证文本放进仓库。fontsource 的包按 unicode-range 切片，一页只下载用到的字。模板为了能直接打开，从 Google Fonts 加载（`family=Saira:wdth,wght@50..125,100..900`），上线前换成自托管。

## 字号

比例约 1.33。

| 变量 | 大小 | 行高 | 字体 |
| --- | --- | --- | --- |
| （大字标） | 随屏宽缩放，可用 `--ef-wordmark` 覆盖 | 0.84 | 界面 800，宽度 125%，大写，字距 -0.02em |
| （空心大编号） | `clamp(5rem, 14vw, 14rem)` | 0.8 | 界面 800，宽度 112%，2px 描边 |
| `--ef-t-h1` | 40px | 1.25 | 界面 700 |
| `--ef-t-title` | 30px | 1.35 | |
| `--ef-t-h2` | 22px | 1.45 | |
| `--ef-t-body` | 17px | 1.85 | 黑体正文 400 |
| `--ef-t-ui` | 15px | 1.6 | 界面 |
| `--ef-t-field` | 13px | 1.5 | 字段，宽度 112% |
| （眉标） | 11px | — | 界面 600，宽度 125%，大写，字距 0.14em |

- App 上字号可以整体小一档（标题 30、正文 16），但比例保持；跟随系统的动态字体大小（Dynamic Type / sp）。
- 阅读栏宽 `--ef-measure: 40rem`，约 38 个汉字一行，左对齐，不两端对齐。
- 页边距 `--ef-pad: clamp(1rem, 4vw, 2.5rem)`：手机 16px，桌面 40px。
- 小切角 `--ef-cut: 7px`；按钮切角 0.5rem；画框切角 3.25rem；看板朝圆盘的切角 1.6rem。

## 缓动

| 变量 | 曲线 | 用在 |
| --- | --- | --- |
| `--ef-ease` | `cubic-bezier(0.2, 0.7, 0.1, 1)` | 普通过渡 |
| `--ef-snap` | `cubic-bezier(0.16, 1, 0.3, 1)` | 出现、到位后稳住：列表行右移、逐行入场 |
| `--ef-mech` | `cubic-bezier(0.7, 0, 0.2, 1)` | 慢起硬停，像机械：快门、擦入、页签伸开、墨色灌满 |
