# 版式与界面范式

前半部分是三种页面类型在**宽屏网页**上怎么搭；后半部分是**手机屏幕**（App、小程序、手机网页）的常见界面怎么做。所有尺寸是逻辑像素。

---

# 一、宽屏（网页、平板、桌面应用）

验收宽度：375、768、1024、1440，都不能出现横向滚动。页边距手机 16、桌面 40。

## A. 阅读页（安静）

模板 `templates/reading.html`，截图 `examples/web/reading-*.jpg`。

```
┌──────────┬─────────────────────────────┬──────────────────────┐
│ 侧栏     │ 白纸（约 640 宽）             │ 页边                  │
│ 192 宽   │  上一级 / 分类               │  目录                 │
│          │  No.024 ◢ 分类｜记录          │  ─────                │
│ ▮ 记录   │  2026.10.17 │ 6,380 字       │  按分类  13 篇        │
│   分类   │  标题（界面字体 700，40）      │  字数合计 48,210 字   │
│   …      │  ━━━━━ 三色条 ━━━━━          │                       │
│          │  正文 / 记录行 …             │                       │
└──────────┴─────────────────────────────┴──────────────────────┘
```

- **侧栏**（≥1100）：竖排导航，当前项是整格黄块（右下切角），每项是 `// EN` 小字 + 中文。更窄时变成顶部横栏；手机上折成 3×2 的格子，不做横向滚动。
- **白纸**：一个阅读栏宽加两侧边距，紧贴侧栏，**左对齐，不居中**。
- **页边**：目录、统计、日历这类旁注，内容都是真实数字。窄于 960 时移到白纸下面。
- 页头顺序：上一级 → 编号和分类标签 → 字段 → 标题 → 三色条（只在详情页）→ 导语 → 标签。
- 列表页：页名加"共 N 篇" → 筛选块 → 按年份或分类分组 → 记录行。**不用卡片网格**。

- 首屏左栏：一行字段统计（数字乱码后落定）、大字标、马克笔一句、简介、2–3 个按钮（只有一个主要操作）。
- 首屏右栏（约 42%）：切角画框加影子加铭牌。图要自己的：线稿、照片、等轴测线图。
- 首屏底：滚动条贯穿全宽。
- 窄于 900：画框移到文字下面，固定高度约 288。

## C. 控制台（大胆但要好用）

模板 `templates/console.html`，截图 `examples/web/console-*.jpg`。

```
┌──────────────────────────────────────────────────────────────┐
│ [A] CONSOLE │▇概览▇ 文章 评论² 统计 备份 │        深浅       │ ← 深色命令栏
├──────────────────────────────────────────────────────────────┤
│ ┌─────────◣              ╭──────╮              ◢─────────┐   │
│ │ 文章 16 0 7│          ╱  概览   ╲          │ 访问 3 58 242│ │ ← 上：向圆盘靠，切朝圆的角
│ └──────────┘        │备份  ◎   文章│        └──────────┘   │
│ ┌────────┐──■      │   中心读数    │      ■──┌────────┐   │ ← 中：退开，引线接到圆
│ │ 互动 …   │        │统计       评论│        │ 作品 …    │   │
│ └────────┘          ╲  用户       ╱          └────────┘   │
│ ┌─────────◤             ╰──────╯             ◥─────────┐   │ ← 下：向圆盘靠，切朝圆的角
│ │ 网站 …    │                                 │ 机器 …    │   │
│ └──────────┘                                 └──────────┘   │
├──────────────────────────────────────────────────────────────┤
│ ┌─▀▀▀── 草稿 ────────────┐ ┌─▀▀▀── 设置 ───────────────┐     │ ← 普通工作看板
└──────────────────────────────────────────────────────────────┘
```

- **没有左侧列表**。命令栏是唯一的导航，两套主题都是深色。
- 中心是分段圆盘（`dial.js`），每段一个入口。
- 左右各三块看板，左右对称、同一行等高，但**不排成规整的表格**：上下两块向圆盘靠拢并切掉朝圆盘的角；中间一块退开，用引线连到圆盘边上。
- 容器宽于 992 时才把看板排到圆盘两侧，否则圆盘在上、看板依次往下排，引线隐藏。
- 下方是普通工作看板：两栏（3:2），窄屏变一栏。
- 控制台的子页面（列表、表单、编辑器）：命令栏加页名（粗体中文、小号英文、斜线纹带），下面筛选条（主操作放最右），内容放在看板里。

## D. 套在已有应用外面

如果里面是一个做好的交互应用（编辑器、可视化），**只换外框**：导航、标题、编号标签、筛选、字体。应用内部的交互和配色保持原样。

# 二、手机屏幕（App、小程序、手机网页）

Flutter 实现见 `templates/flutter/`，截图 `examples/app/`（390×844）；同一套界面的网页实现见 `templates/app.html`，截图 `examples/web/app-*.jpg`。下面每条都写了含义，平台写法见各平台指南，进出和状态变化的动效见 `motion.md`。

## 屏幕骨架

```
┌──────────────────────────┐
│ ▇ 状态条 / 安全区          │ ← 首屏可用深色命令栏，其余屏幕用纸色
│ // RECORDS          [筛选]│ ← 顶栏：眉标 + 中文粗体标题，右侧至多 1–2 个文字按钮
│ 记录                      │
├──────────────────────────┤ ← 1px 细线，没有投影
│                          │
│  内容（左右 16 边距）       │
│                          │
├──────────────────────────┤
│ ▇HOME▇  RECORDS  STATUS  CONFIG │ ← 底部标签栏
│ ▇总览▇   记录     状态     设置   │
└──────────────────────────┘
```

- 背景是纸色，右上、左下两角极淡的等高线。
- 顶栏**不填色、不居中、不加投影**：左对齐的中英成对标题，下面一条细线。返回键是一个小的切角按钮 `‹`，不用圆形图标按钮。
- iOS 大标题、Android 顶部应用栏的位置照用，只是换成这套样式。

## 底部标签栏

- 白底（板色），上沿一条细线；3–5 项。
- 每项是英文眉标（9–10，宽 125%，大写）+ 中文（14）。**必须有文字**，不只放图标。图标可选，用 1.5px 线性图标，不填色。
- 当前项：整格黄块、右下切角、中文加粗。切换时黄块用 mech 曲线移动（280ms），没有涟漪。
- 高度 ≥ 52 加底部安全区。

## 首屏 / 总览（展示或控制台类型）

截图 `examples/app/home-*.jpg`。

- 顶部深色命令栏：黄色小方块 + 品牌名（宽体 700）+ 右侧一行真实状态字段。下面紧贴三色条。
- 眉标 `// FIELD ARCHIVE / 2026` → 宽体大字标（48–72，800，宽 125%）→ 中文粗体副标题 → 字段行。
- 一块看板：三个大数字，需要处理的那个垫黄。
- "最近"段：中英成对标题，右边一个小按钮"全部"；下面三条记录行，最新那条的编号是黄色（当前）。

## 列表

截图 `examples/app/list-*.jpg`。

- 搜索框：白底细线，前缀 `//`，聚焦时下边变 2px trace 线。
- 筛选块横排可换行（不做横向滚动条）；选中的是黄色。
- 分组眉标 `// 2026 / OCTOBER`，下面记录行：第一行编号标签、日期、右侧计数；第二行名称（黑体 16，500）。
- 按下：左边 4px trace 色条落下，整行右移 6px（200ms snap）。
- 下拉刷新：顶部出现一条分段进度条和 `SYNC 063%` 读数，不用转圈。
- 左滑操作：露出切角的文字按钮（"移到草稿"灰、"删除"红），不用图标。

## 详情（阅读类型）

截图 `examples/app/detail-*.jpg`。

- 编号标签（黄 = 当前这一条）+ 状态框 → 标题（30，700）→ 三色条 → 字段行。
- 导语里最多一处黄色马克笔，说明"这是什么"。
- 正文黑体 16–17，行高 1.8–1.85；小标题前一条 4px trace 竖条，后面拖斜线纹带。
- 底部操作条：一个主要按钮（黄，占满）+ 一个次要按钮。

## 表单 / 设置

截图 `examples/app/settings-*.jpg`。

- 字段：标签在上（13，600，次要墨色），白底输入框细线框，聚焦时下边 2px trace；说明写在框下面（12），不写在占位符里。
- 开关：方形。开 = 黄色轨道 + 墨色方块；关 = 浅灰轨道 + 白色方块。
- 分段选择：墨色细框，当前段墨底反白（不用黄：黄留给导航"当前"和主要操作）。
- 设置项每行：名称（16，600）+ 说明（12），右侧控件，下面细线。
- 底部：主要按钮（黄，满宽）；危险区在最下面，眉标 `// DANGER`，按钮字是红色，按下时红色擦入。

## 底部面板 / 操作菜单

截图 `examples/app/sheet-*.jpg`。

- 遮罩 `scrim`（墨 50%），不加模糊。
- 面板板色，**左上角切掉**（26），顶部 18 高的斜线纹带，中间一根 40×4 墨色把手。
- 标题：眉标写对象（`// NO.023 / ACTIONS`）+ 中文粗体。
- 每个操作一行（≥ 52 高），上面细线，右侧可放字段（如字数、编号）和 `›`。删除那行字是红色。
- 最下面一个"取消"按钮。打开用 mech 曲线从下推入 360ms，不弹跳。

## 对话框

截图 `examples/app/states-dialog-*.jpg`。

- 就是一块看板：白板、顶边粗墨页签、右下切角。
- 眉标 `// CONFIRM` + 中文问题；一句说明后果的话；右下两个小按钮，确认在右。删除确认的按钮用红色。

## 状态：加载、空、提示

截图 `examples/app/states-*.jpg`。

- 加载：分段进度条（24 格，亮的格是黄）+ `SYNCING / 同步中` 眉标 + `063%` 读数。不用转圈；不知道进度时，让一段黄格从左往右走（这是唯一允许循环的情况，因为它表示"正在进行"，完成即停）。
- 骨架屏：用 chip 色的矩形块，不做闪光扫过。
- 空状态：细线框里铺斜线纹，中间一块纸色底的句子，下面一个主要按钮。
- 提示条（toast）：深色条，左边 6px 黄色竖条，一句话，2 秒后硬切消失。
- 横幅提示：白底细线框，左边一面黄色小旗 `!`，一句话。错误也是黄旗，不用红。

## 启动页

- 纸色或深色底，居中偏上的宽体字标；底部一条分段进度条和读数；角落一片等高线。
- 不放 logo 动画循环；进度到 100% 后快门切走（360ms mech）。

## 平板与横屏

- 宽于 600 时：底部标签栏变成左侧竖排导航（当前项仍是黄块）；列表和详情左右分栏（列表 360 宽，当前行编号变黄）。
- 宽于 992 时：总览可以用桌面控制台的布局（看板围着圆盘）。
