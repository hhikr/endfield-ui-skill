# 术语表

这个 skill 里有很多为了说清设计而起的简称。它们**只给你（agent）理解用**，不是界面文案。

- 产品界面、用户文档、宣传文字里**不出现这些词**。界面上的字用产品自己的业务词汇。
- 只有当产品本身就在介绍这套设计（比如这个 skill 的演示页、说明视频）时，才需要讲这些概念，那时用"对人怎么说"这一列。
- 英文眉标是中文标题的直译，不用这里的英文 token 名（signal、trace、chip……）当标签。

## 总体概念

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 页面类型（阅读 / 展示 / 控制台） | 按用途分的三种页面，决定排版敢不敢大 | 阅读页 / 展示页 / 控制台 |
| 固定规则 | 每个产品都不能改的几条：一种强调色、红色只给删除、切角表示可点击、宽体英文配粗体中文、真实数据、细线、机械动效 | 基本规则 |
| 外观 / 变体 | 每个产品可以换的六项：强调色、纸色、切角、底纹、密度、动效 | 外观设置 |
| 预设（standard / coldstore / site / nightshift） | 四组现成的外观搭配 | 标准 / 冷库 / 工地 / 夜班，或"四种现成搭配" |
| 主题 | 只指浅色 / 深色 | 浅色 / 深色 |
| 变体卡 | 交付说明开头的三行设置记录 | 不对外说 |
| 主视觉 | 首屏或控制台中间放的主图 | 首页大图、主图 |
| 气质 | 整体给人的感觉 | 风格 |

## 颜色

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 强调色、signal、accent、黄色 | 同一个东西：唯一的亮色，默认 `#FFFA00` | 亮色、高亮色 |
| 当前位置 / 可点击 / 需要注意 | 强调色只能用在这三种地方 | 原样说 |
| 纸、paper | 页面底色 | 底色、背景色 |
| 板、panel | 白色卡片 / 面板的底色 | 卡片底色 |
| 墨、ink | 正文和线条的近黑色 | 黑色、文字颜色 |
| trace | 标出当前位置的线的颜色：浅色主题是墨，深色主题是强调色 | 高亮线 |
| chip | 浅灰色的安静填充 | 浅灰底 |
| 三色条 | 品红 / 黄 / 薄荷绿三等分的细条 | 三色细条 |

## 部件

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 眉标、eyebrow | 标题上方那行拉宽的英文小字，常带 `//` 前缀 | 英文小标题 |
| 中英成对 | 英文小字在上、中文粗体在下的标题 | 中英双行标题 |
| 字标、wordmark | 用文字做的标志，或展示页的超大标题字 | 大标题、标志字 |
| 字段、真实字段 | 编号、日期、字数、计数这类元数据，必须是真数据 | 编号、日期、数量（直接说是什么） |
| 编号标签 | 墨底白字、切一个角的 `No.024` | 编号 |
| 记录行 | 列表里一整行：编号 / 日期 / 名称 / 计数 | 列表项、一行 |
| 看板 | 控制台上显示一组数据的面板 | 数据块、面板 |
| 页签 | 看板顶边那段粗线 | 不对外说 |
| 分段圆盘 | 控制台中间分成几段的圆形导航 | 圆形导航 |
| 命令栏 | 控制台和 App 顶部的深色横条 | 顶栏 |
| 画框 | 展示页里切角的大边框 | 图片边框 |
| 斜线纹、hatch | 45° 细斜线填充 | 斜线底纹 |
| 等高线、contours | 两角很淡的弯曲线条 | 背景纹理 |
| 切角 | 切掉一个角，表示能点 | 切角 |
| 马克笔 | 标题下用强调色涂的一句话 | 荧光笔高亮 |
| 小旗 | 提示前面那块小色块 | 提示标记 |

## 交互和动效

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 悬停（旧称"指向"） | 鼠标放在上面 | 悬停、鼠标移上去 |
| 可点击（旧称"可按"） | 能点的东西 | 能点 |
| 擦入 | 颜色从左往右扫进来 | 颜色扫过 |
| 通电 | 面板从上往下展开出现 | 面板展开 |
| 快门 | 换页时新页面从一侧斜切推入 | 换页动画 |
| 灌满 | 颜色从一边填满 | 填色 |
| 乱码后落定 | 文字先乱跳再定格 | 文字跳动后定格 |
| 逐行亮起 | 列表一行接一行出现 | 列表逐行出现 |
| 圆盘组装 | 圆形导航的几段依次拼上 | 圆盘拼合 |
| 页签伸开 | 面板顶边的粗线伸长 | 面板标记伸长 |
| 锁定 | 悬停圆盘某段时把它框住 | 选中 |
| 揭幕 | 深浅主题切换时扩散一个圆 | 深浅色切换 |
| snap / mech / ease | 三条动画曲线 | 不对外说，必要时说"出现 / 机械式 / 普通过渡" |
