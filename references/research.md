# 调研：终末地的界面语言

2026 年 10 月对《明日方舟：终末地》官网（国服 endfield.hypergryph.com、国际服 endfield.gryphline.com）、官方发布的游戏截图和两个玩家 wiki 的调研浓缩版。截图是第三方版权素材，只作参考，没有放进这个 skill；需要核对时，自己去官网和官方渠道看。

标记：**【测】** 从官网样式表或截图像素读出的数值；**【看】** 在截图里直接看到的；**【猜】** 推测，没有直接证据。

## 1. 颜色

| 用途 | 色值 | 来源 |
| --- | --- | --- |
| 官网页面底色 | `#FFFFFF` | 【测】 |
| 主黄 | `#FFFA00` | 【测】干员页多边形、新闻横幅、选中块 |
| 深色页面上的黄 | `#FDFD1F` | 【测】 |
| 近黑（字、标签底） | `#191919`，不是纯黑 | 【测】 |
| 浅灰面板阶梯 | `#FAFAFA` `#F2F2F2` `#EDEDED` `#E6E6E6` `#D9D9D9` | 【测】靠色块差分区，很少画描边 |
| 次要文字 | `#8A8A8A` `#999999` | 【测】 |
| 游戏内界面底 | 浅灰到中灰（`#808080` 上下），内容在炭黑行 `#252525`–`#353535` 上 | 【看】游戏内不是纯白 |
| 三色色标 | 官网：品红 `#FF00F0`、黄 `#FFFA00`、薄荷绿 `#00FFA2`；游戏内：青、品红、黄 | 【测】面积极小、三色紧贴、贴着标题或分隔线 |

**结论**：官网是"白底加明黄"，游戏内是"灰底加炭黑面板，黄色表示选中或可领取"。等高线存在，但淡到几乎看不见（官网新闻页最深处 `#EFEFEF` 压在白底上）。

## 2. 字体

- 【测】官网中文用一组无衬线体（Regular / Medium / Bold / Black），英文标签用宽体大写（类似 Novecento Wide）。正文 12.5–15px，标题 24px 左右。
- 【看】英文和数字比中文"宽"、"几何"，大量全大写；**中英成对出现**：英文小字在上或在旁，中文粗体在下（`LORE / 世界观资料`）。
- 【看】超大英文字只当背景用，并用 45° 细斜线裁进字形，做成"镂空"效果。
- 【看】游戏内标题常以 `//` 开头：`// 地区建设 /仓储节点`。

**我们的转译**：官方字体不能用，也没必要用。用 **Saira**（开源可变字体，有宽度轴）承担宽、几何、大写的英文和数字：字段拉到 112%，标签和字标拉到 125%；中文用干净的黑体（思源黑体 / 系统中文字体），界面粗、正文常规。中英成对、`//` 前缀都保留：`// RECORDS` / `记录`。正文也用黑体：游戏和官网里没有楷体、宋体这类"书卷气"的字。

## 3. 形状与边框

- 【看】直角为主，胶囊为辅，几乎没有中等圆角。【测】卡片圆角 4px，按钮 2px。
- 【看】很少画描边，靠灰度色块分区；游戏内炭黑行之间留缝，不画线。
- 【看】斜切和平行四边形：页签右上角斜切、立绘裁成倾斜条、`clip-path` 多边形色块。
- 【看】L 形角标：只画两个角，代替完整边框。
- 【看】细线一端带小方块或小圆圈，像电路图的端子。
- 【看】45° 斜线填充用于空档、禁用区、深色按钮表面。

**我们的转译**：全部直角；"切掉一个角"统一表示"可以点"；细线加端点用作看板到圆盘的引线；斜线纹用作标题后的带子和画框的影子。胶囊形按钮**没有采用**，因为和切角语言冲突。

## 4. 排布

- 【看】官网桌面端是左侧窄竖条导航，内容满宽；长页面分段，浅段深段交替。
- 【看】段标题是固定组件：极小的 `▼// ENDFIELD`、英文段名、中文粗体段名、三色竖条。
- 【看】键值信息用**成对小标签**：左深底白字是键，右浅灰底深字是值，等高紧贴。
- 【看】游戏内列表是整行横条，一行一条记录，从左到右：头像、名字、信息列、状态、操作。
- 【看】游戏内全屏界面：左上 `//` 面包屑标题，右上关闭按钮，底部深色状态栏放说明和主操作。
- 【看】大数字加小单位：`LV.70` 里 `LV.` 很小、`70` 很大。

**我们的转译**：成对小标签就是键值块；整行记录就是记录行；大数字加小单位用在看板和圆盘中心；左侧窄导航用在桌面网页的阅读页，App 上换成底部标签栏（当前项整格黄，和官网选中项一致）；游戏内全屏界面的"左上 `//` 标题、底部深色状态栏放主操作"直接搬到 App 的顶栏和底部操作条。

## 5. 标注和编号

- 【看】补零编号 `01 02 03`、`010 / 010 LAST`；行的左侧再用很大的半透明 `01` 做底纹。
- 【看】`当前 / 总数`：`1 / 35`、`27/100`。
- 【看】日期用点分隔：`2026.10.07`。
- 【看】方括号括住重点词：`[ REC ]`。
- 【看】装饰性假技术文字（`MISSION-DEPENDENT…`、二进制串、条形码、坐标）、十字定位标记、一排小方点。它们都只起质感作用。

**我们的转译**：编号、日期、`当前 / 总数` 全部采用，而且**必须是真实数据**；补零大编号变成"空心大编号"。假技术文字、条形码、十字、小方点**一律不用**：在真实产品里它们只是噪音，对读者没有信息。

## 6. 动效

- 【测】官网过渡集中在 0.2–0.3 秒，位移最长 0.4–0.5 秒。
- 【看】加载页：深底，左边一条黄色竖条随百分比变长，大号黄色百分比数字，背景极淡的等高线。
- 【猜】各段是滚动触发入场；形式没看到。
- 游戏内的动效没有看到。

**我们的转译**：没有照抄具体动画，而是定下原则：短、硬、机械，每个动效对应一次操作。机械感来自缓动曲线（慢起硬停的 `--ef-mech`）和动作类型（快门、擦入、通电、乱码后落定）。

## 7. 玩家 wiki 怎么转译的（参考别人保留了什么）

- fz.wiki：顶部贯穿全宽的三色细线；左侧导航"中文加一行宽字距英文"，选中项整格变黄；圆角全为 0；黄偏金（`#D8BF00`）；背景一层淡方格。
- endfield.wiki.gg：深色主题，页签下一条三色细线，标题下一排斜线。

共同点：**三色细线、整格黄色选中、零圆角、斜线**。这几样是辨识度最高、也最好搬的。

## 8. 可以借的 / 不要借的

| 借 | 不借 |
| --- | --- |
| 白或浅灰底、近黑墨、一种明黄 | 官方字体文件、标志、图标、插画、截图、文案 |
| 黄色只表示"选中 / 可领取 / 当前" | 大面积铺黄、黄底黑字的大横幅 |
| 切角、斜线填充、细线加端点 | 胶囊按钮、发光、扫描线、霓虹 |
| 成对键值标签、整行记录、补零编号、点分日期 | 假技术文字、条形码、十字标记、装饰小方点 |
| 三色细条（一屏一两处） | 三色做大面积装饰或渐变 |
| 极淡、不闭合的等高线 | 点阵、网格纸、闭合的山丘等高线 |
| 中英成对的标签 | 满屏全大写 |
